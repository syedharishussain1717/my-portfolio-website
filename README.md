# my-portfolio-website
Personal Portfolio Website

React | HTML | CSS | JavaScript | Bootstrap | Node.js | Express.js | MongoDB | Mongoose

Developed a responsive personal portfolio website using React, with reusable components and React Router for seamless page navigation.
Designed user-friendly layouts and interactive sections, including animated text, project showcases, and a functional contact form.
Developed a Node.js and Express.js backend with REST API integration to handle contact form submissions.
Integrated MongoDB with Mongoose to securely store and manage contact messages.
Implemented CORS to enable communication between the React frontend and backend.
